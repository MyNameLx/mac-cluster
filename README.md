# mac-cluster

mac-cluster 是一个面向 Mac/PC 异构设备的本地 AI 集群管理项目。

项目将一台闲置的老款 Mac 作为集群中枢，统一发现、连接和管理局域网中的多台 Mac / Windows / Linux 设备，并负责分发和监控 AI 任务及其他进程。

## 核心目标

- 使用老款 Mac 作为稳定的控制中枢
- 管理局域网中的多台 Mac 和 PC
- 支持远程启动、停止和监控进程
- 分发 AI 推理、训练、批处理等任务
- 收集节点状态、资源占用和任务执行结果
- 构建轻量、可扩展的本地分布式计算环境

## 规划中的技术栈

- **控制端：** Go / Rust
- **节点端：** Go / Rust
- **通信：** WebSocket / gRPC / HTTP API
- **任务格式：** JSON / 可扩展任务描述
- **部署方式：** 本地编译、脚本启动或容器化
- **操作系统：** macOS、Windows、Linux

具体实现方式可根据实际场景选择；控制端优先考虑跨平台、低资源占用和易部署性。

## 系统架构

```text
                       ┌──────────────────┐
                       │   老款 Mac 中枢  │
                       │  控制 / 调度层   │
                       └───────┬──────────┘
                               │
               ┌───────────────┼───────────────┐
               │               │               │
        ┌──────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐
        │   Mac 节点  │ │   PC 节点   │ │  其他节点   │
        │ AI / 普通任务│ │ AI / 普通任务│ │ AI / 普通任务│
        └─────────────┘ └─────────────┘ └─────────────┘
```

中枢负责节点管理和任务调度，各节点负责接收任务、执行进程并上报运行状态。

## 规划功能

- 节点自动发现与手动注册
- 节点在线状态和心跳检测
- CPU、内存、磁盘和 GPU 状态监控
- 任务创建、排队、分发与取消
- 多任务并发和资源配额控制
- 任务日志、退出码及结果回传
- 命令行管理与 Web 控制台
- 失败重试和任务迁移
- 本机、公网和局域网访问控制

## 工作流程

1. 在各台 Mac / PC 上启动节点进程。
2. 节点向老 Mac 中枢注册并建立持续连接。
3. 中枢收集节点状态并维护可用资源。
4. 用户通过控制端提交 AI 或普通任务。
5. 调度器选择合适节点并下发任务。
6. 节点执行进程并持续上报日志与运行状态。
7. 中枢汇总任务结果，并提供查询和管理能力。

## 安全说明

集群应优先部署在受信任的局域网中。建议在后续版本中加入：

- 节点身份认证
- TLS 加密通信
- 访问令牌和最小权限
- 白名单与防火墙配置
- 敏感任务参数加密
